# piotrwilam.github.io

Personal page, built by GitHub Pages with Jekyll and the minima theme. The content is
`index.md`; edit it and push, and the site rebuilds within a minute or two.

- `_config.yml` — title, description, footer links
- `_includes/header.html` — the header's section links
- `assets/main.scss` — minima plus hairline rules and a dark palette
